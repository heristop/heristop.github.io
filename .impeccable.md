## Design Context

### Users
Visitors to Zazen Code exploring a short tactical garden game on desktop, phone or controller. The garden reflects @heristop's GitHub activity; challenge stays balanced regardless of activity.

### Brand Personality
Quiet, crafted, playful. Delight comes from readable pixel characters, responsive interactions and a living garden.

### Aesthetic Direction
Original isometric pixel art inspired by classic tactical RPGs and HD-2D presentation. Ink-blue surfaces, parchment text, restrained brass accents and atmospheric scenery. Preserve compact desktop board proportions and comfortable mobile panning.

### Design Principles
- The board is the focus. Present the current objective once; disclose secondary statistics and card explanations on demand.
- Keep information in the page when possible, without covering play with additional overlays.
- Align related panels and maintain consistent spacing, legible type, 44px minimum controls and visible keyboard focus.
- Use Lucide for interface icons and pixel sprites for the game world.
- Animate meaningful changes briefly; respect reduced motion and preserve keyboard, touch and controller access.
